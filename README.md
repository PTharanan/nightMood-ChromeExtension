🌓 Night Mood – Chrome Extension

Night Mood is a Chrome extension that applies Dark Mode only to the content area of a website while keeping the navbar and header unchanged. It helps you read comfortably without affecting the website’s layout.

🚀 How It Works

Night Mood temporarily adds a dark theme to the content of any website:

The page background becomes dark

Text becomes white

Images are slightly dimmed

Only the article/content area changes

Navbar, header, and menus stay in original style

When you turn it OFF, the website instantly goes back to its original design.
No changes are saved permanently — everything is removed cleanly.

🧪 Using the Extension in Developer Mode

Since this extension is not published yet, you use it through Developer Mode:

Open Chrome and go to:
chrome://extensions/

Turn on Developer mode (top right switch)

Click Load unpacked

Select the extension folder

The Night Mood icon now appears in your Chrome toolbar

You can now use the extension normally.

🖱️ How to Use

Open any website

Click the Night Mood icon

Press ON

Content switches to dark mode

Navbar/header remain unchanged

Press OFF

Website returns to its original look

You can toggle ON/OFF anytime. The extension applies changes instantly.

📌 Summary

Dark mode only affects content

Navbar stays in original color

Simple ON/OFF toggle

Works through Chrome Developer Mode

No permanent changes to websites
